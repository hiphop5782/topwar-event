# 관리자 사용 가이드

이 문서는 이벤트 운영자가 실제 진행 중 참고할 수 있는 사용법을 정리합니다.

## 관리자 접속

기본 주소 뒤에 `?admin`을 붙여 접속합니다.

예시:

```txt
https://example.com/?admin
```

비밀번호 입력창이 뜨면 `3223`을 입력합니다.

## 상태 의미

- `선택 진행 중`: 참여자가 선택을 저장할 수 있습니다.
- `선택 마감`: 참여자 선택은 막히고, 관리자가 당첨 칸을 발표할 수 있습니다.
- `당첨 발표`: 당첨 칸과 당첨자가 화면에 표시됩니다.

## 기본 진행 순서

1. `사용자당 선택 개수`를 입력합니다.
2. `당첨 인원`을 입력합니다.
3. 중복 당첨을 허용할지 선택합니다.
4. `설정 적용`을 누릅니다.
5. 필요하면 `선택 금지 칸 편집`을 눌러 보드에서 금지할 칸을 선택합니다.
6. `선택 시작`을 눌러 참여자가 선택할 수 있게 합니다.
7. 참여가 끝나면 `선택 마감`을 누릅니다.
8. 보드에서 발표할 칸을 클릭합니다.

## 당첨 인원 규칙

`당첨 인원`은 한 번 발표할 때 뽑을 인원 수입니다.

예시:

```txt
당첨 인원 = 3
```

해당 칸을 선택한 사람 중 최대 3명이 당첨자로 기록됩니다.

현재 정렬 기준은 선택 저장 시점입니다. 먼저 저장한 사용자가 먼저 당첨자로 선정됩니다. 저장 시간이 같으면 이름순으로 정렬됩니다.

## 중복 당첨 허용

`중복 당첨 허용`이 켜져 있으면 이전에 당첨된 사람도 다시 당첨될 수 있습니다.

꺼져 있으면 이미 당첨 내역에 포함된 사람은 다음 발표에서 제외됩니다.

## 선택 금지 칸

`선택 금지 칸 편집`을 누른 뒤 보드의 칸을 클릭하면 금지 칸으로 지정하거나 해제할 수 있습니다.

금지 칸은 참여자가 선택할 수 없고, 관리자가 당첨 칸으로 발표할 수도 없습니다.

기존 참여자의 선택에 금지 칸이 포함되어 있으면 자동으로 제거됩니다.

## 초기화 버튼

- `선택만 초기화`: 참여자 선택만 삭제합니다. 당첨 내역과 금지 칸은 유지합니다.
- `당첨 내역만 초기화`: 당첨 발표 기록과 현재 당첨 칸만 삭제합니다. 참여자 선택과 금지 칸은 유지합니다.
- `모든 내역 초기화`: 참여자, 당첨 내역, 금지 칸, 설정을 초기 상태로 되돌립니다.

## 당첨 발표 화면

당첨 칸이 발표되면 다음 내용이 표시됩니다.

- 현재 당첨 칸
- 당첨자 닉네임 목록
- 누적 당첨 인원
- 당첨 내역
- 축하 모달과 컨페티 효과

이미 축하 모달이 열려 있는 상태에서 새 발표가 들어오면 기존 모달을 제거하고 새 모달을 표시합니다.

당첨자가 없는 칸을 발표하면 축하 문구와 컨페티 없이 당첨자가 없다는 안내만 표시됩니다.

알림창은 자동으로 사라지지만, `X` 버튼, 바깥 영역 클릭, `ESC` 키로 바로 닫을 수 있습니다.

## 문제 상황별 확인

### 참여자가 선택 저장을 못 하는 경우

- 상태가 `선택 진행 중`인지 확인합니다.
- 참여자가 이름을 입력했는지 확인합니다.
- 정해진 개수만큼 칸을 선택했는지 확인합니다.
- 선택한 칸에 금지 칸이 포함되어 있는지 확인합니다.

### 당첨 칸 발표가 안 되는 경우

- Firebase 연결이 정상인지 확인합니다.
- 선택 금지 칸을 발표하려는 것은 아닌지 확인합니다.
- 관리자 화면으로 접속했는지 확인합니다.

### 당첨 내역만 다시 뽑고 싶은 경우

`당첨 내역만 초기화`를 누르면 참여자 선택은 유지되고 발표 기록만 사라집니다. 이후 보드에서 다시 당첨 칸을 발표하면 됩니다.
