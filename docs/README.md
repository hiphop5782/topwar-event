# Topwar Event 문서

이 저장소는 3223 서버 수도장 포상 이벤트에서 사용하는 8x8 위치 선택/추첨 웹앱입니다.

참여자는 보드에서 정해진 개수만큼 칸을 선택하고, 관리자는 선택을 마감한 뒤 당첨 칸을 발표합니다. 발표 결과는 Firebase Firestore에 저장되어 모든 화면에 실시간으로 반영됩니다.

## 주요 기능

- 사용자별 닉네임 입력 및 칸 선택
- 사용자당 선택 가능 개수 설정
- 선택 금지 칸 지정
- 선택 마감 및 당첨 칸 발표
- 당첨 인원 수 설정
- 중복 당첨 허용 여부 설정
- 당첨 발표 시 축하 모달과 컨페티 효과
- 누적 당첨 인원 및 당첨 내역 표시
- 선택만 초기화, 당첨 내역만 초기화, 전체 초기화
- Firebase Firestore 기반 실시간 동기화
- 국기 버튼 기반 다국어 번역

## 주요 파일

- `public/index.html`: 화면 구조
- `public/app.js`: 앱 동작, Firebase 연동, 관리자/사용자 로직
- `public/styles.css`: 화면 스타일과 애니메이션
- `public/firebase-config.js`: Firebase 설정과 이벤트 ID
- `FIREBASE_SETUP.md`: Firebase 프로젝트 설정 요약
- `server.js`: 로컬 테스트용 Node 서버

## 다국어 번역

상단 국기 버튼을 누르면 언어 버튼을 제외한 화면의 한국어 텍스트를 JSON으로 모아 Google Apps Script 번역 API에 전달합니다.

지원 언어:

- 한국어
- 영어
- 베트남어
- 일본어
- 스페인어
- 포르투갈어
- 아랍어
- 중국어

번역 중에는 대상 텍스트가 샤이닝 placeholder로 표시됩니다. 번역 실패나 API 오류가 발생하면 toast 메시지가 표시됩니다.

## 화면 모드

- 사용자 화면: 기본 접속 주소
- 관리자 화면: 주소 뒤에 `?admin`을 붙여 접속

관리자 화면은 접속 시 비밀번호 프롬프트가 뜨며, 현재 비밀번호는 `public/app.js` 안에 있는 `3223`입니다.

## 운영 흐름 요약

1. 관리자가 관리자 화면으로 접속합니다.
2. 사용자당 선택 개수, 당첨 인원, 중복 당첨 허용 여부를 설정합니다.
3. 필요하면 선택 금지 칸을 지정합니다.
4. `선택 시작` 상태에서 참여자가 이름과 칸을 선택해 저장합니다.
5. 관리자가 `선택 마감`을 누릅니다.
6. 관리자가 보드의 칸을 클릭해 당첨 칸을 발표합니다.
7. 당첨 발표가 모든 화면에 반영되고 축하 모달이 표시됩니다.
